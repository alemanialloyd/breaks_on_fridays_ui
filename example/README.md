# breaks_on_fridays_ui example

A visual gallery of every `BoF.*` widget, for eyeballing layout/rendering.
Not a demonstration of real-world usage — see the parent package's README for
that.

Run it:

```
cd example
flutter run -d windows   # or chrome, macos, etc.
```

Scroll through the Core, Display & layout, and Form fields sections, and use
the sun/moon icon in the app bar to check both light and dark themes.
